# v8.1 全景書房（360° 房間＋走動＋窗景光影）

發布日期：2026-10-17  
狀態：實作於 `arena/950f9b50-test222`；本文件描述實作與驗收 gate。

## 1. 設計摘要

將 v8.0 的平面外殼換成**可環繞、可在室內走動的 three.js 房間**。採 WebGL／HTML 雙層，而非把互動畫布紋理化：

- **WebGL 層**：4 面牆、天花、木地板、大窗與窗櫺、庭園分層景片、窗下壁掛桌、另一牆的書架與 3D 書本、日光與軟影。
- **HTML 浮層**：既有 `InfiniteCanvas`、卡片編輯器、書封預覽、書架目錄、分類 CRUD、HUD、搖桿。文字輸入、Pointer Events、IME、無障礙語意與原畫布程式碼不變。
- **不改**：`InfiniteCanvas.tsx` 手勢、`seedData.ts` 種子資料、`inspect.ts` 審查引擎；卡片開啟仍走 `page.tsx` 的既有 `CardDetailModal`。

## 2. 已確認決策的實作

### three.js 與 HTML 雙層

新增唯一 runtime dependency `three`（並以 `@types/three` 作 TypeScript 開發型別）。`StudyScene` client 掛載後建立 `WebGLRenderer`、scene、camera、ResizeObserver 和 rAF；卸載時解除監聽、釋放 geometry/material/texture/renderer。`webglcontextlost` 顯示重載提示。渲染器用 antialias、ACES Filmic、PCFSoftShadowMap；DPR 上限桌機 2、手機 1.5。

### 點桌面進工作視角：仿射映射而非 CSS 3D

房間模式的桌面紙面是 Three.js 可 raycast 的靜態縮圖；房間模式不把點擊手勢交給畫布。點擊桌面後，`CameraRig` 約 520 ms ease-in-out 飛至桌面上方，camera up 軸沿房間北向，視線垂直桌面。原 `InfiniteCanvas` 以固定螢幕平行 HTML layer 完整顯示；不旋轉 DOM 畫布、不投影成 WebGL 紋理，因此其 `getBoundingClientRect()` 座標換算是純仿射。畫布始終掛載，進出工作視角不重置 pan/zoom。

Esc／「回到房間」按鈕開始返航，使用進入前完整保存的相機位置、四元數、FOV 和 up 軸；動畫期間忽略相機輸入。書本「在畫布定位」會先飛入工作視角，再呼叫現成 `apiRef.focusCard(cardId)`。

### 走動／環顧／手勢

- 桌機 WASD／方向鍵走動，Shift ×2；滑鼠拖曳轉視角。
- 觸控手機左下搖桿走動，畫面拖曳環顧。搖桿獨立使用 Pointer Events，不攔截畫面環顧。
- yaw 360° 連續並正規化儲存，pitch 限制 −70°～+40°；移動約 2.2 m/s，位置夾於房間內牆面 0.35 m 範圍；滾輪小幅調整視高。
- 聚焦 input/textarea/select/contenteditable 或 HUD 時不走動；工作模式中 WASD 對畫布無效。飛行期間忽略操作。
- 書架 3D 射線命中產生 HTML 書封預覽；「書架目錄」提供可 Tab 操作、點擊面積至少 40px 的替代入口。預覽提供分類 select、排序上下鈕、開卡和畫布定位。分類面板保留完整 CRUD。

### 空間關係

房間寬 6 m、深 5 m、高 3.1 m。北牆大窗約 3.4 m 寬，窗台高 1.02 m；壁掛桌面高 0.78 m，無桌腿、有桌板厚度、前緣與牆面支撐角件。東牆放書架，並非窗牆；其他牆、天花與地板為低對比木色／米白材質。

### 光影／效能取捨

- 太陽參數集中在 `room3d.ts`，單一淡金方向光自窗外左上射入；窗框、窗櫺是實體可投影幾何，桌面與木地板接收 PCF soft shadows。
- 庭園是程序化分層幾何（天空遠景、遠樹帶、分層樹冠、近灌木、草地），沒有外部大型圖片資產。木紋、牆面顆粒、地板板縫為 canvas 貼圖。
- 桌機啟用 3 片低透明光柱與 140 顆塵埃點；手機關光柱／粒子、shadow map 降為 1024、DPR ≤1.5。場景物件材質共享，動畫只更新相機與少量粒子。
- 光柱採透明幾何而非高成本體積光；庭園以低面數程序化景片代替高解析外部照片。這是視覺品質與手機效能的折衷。

## 3. 資料相容

`StudyLayout.camera` 現有 `yaw/pitch` 之外新增可選 `x/z/height`（公尺）。`ensureStudyState` 對舊資料補為 x=0.9、z=1.55、height=1.5，pitch 夾限；yaw 正規化為 360° 連續角。`STORAGE_KEY=scinotes-workspace-v8.0`、`SCHEMA_VERSION=8` 均維持不變，無結構性遷移；JSON 匯出照舊整包帶出欄位。

`studyBooks` / `studyCategories`、`applyPatch`、卡↔書 1:1、佈置與畫布座標隔離規則不變。`store.ts` 的 `updateStudyLayout` 以 camera 部分合併，舊呼叫者傳 yaw/pitch 不會清掉 x/z/height。

## 4. 檔案責任

- `src/lib/room3d.ts`：房間／窗／桌／書架尺寸、日光與畫質設定、視角限制、位置限制、相機投影 helper、書架版面純計算。
- `StudyScene.tsx`：three.js renderer、resize、rAF、失焦暫停、dispose、context loss。
- `RoomGeometry.tsx`：房間、窗框窗櫺、壁掛桌、靜態畫布縮圖、書架本體。
- `WindowLight.tsx`：室內光源與窗外植物景片、桌機光柱／塵埃。
- `CameraRig.tsx`：滑鼠／觸控、WASD、搖桿速度、碰牆限制、工作視角飛入／返回。
- `Joystick.tsx`：手機 HTML 搖桿。
- `Book3D.tsx`：3D 書本、標題貼圖、分類標籤；射線命中以 cardId 導向 HTML 預覽。
- `DeskWorkView.tsx`：唯一 `InfiniteCanvas` 工作畫布浮層（維持掛載以保留 zoom/pan）。
- `StudyRoomView.tsx`：場景組裝、HTML 書封預覽／書架目錄／分類 HUD、相機與畫布接線。

v8.0 `BookshelfView.tsx`／`BookSpine.tsx`／`DeskCanvas.tsx` 未刪除、不再作為 v8.1 實際視圖路徑；書本排序改由 3D 書本預覽中的分類選單與上下按鈕完成，鍵盤使用者亦可透過書架目錄開預覽。

## 6. 已知限制

- 窗外景物是程式化低面數景片，不是照片級庭園；透明光柱是淡化片狀光，不是體積光。
- 書本排序與換櫃板使用 HTML 書封預覽中的 select／上下按鈕，不做 3D 拖書，避免 WebGL raycast 拖曳與觸控環顧互搶。
- 房間碰撞採內部 AABB 邊界夾限，不做家具級碰撞；角色不會穿外牆，但可在房內穿越桌／書架區域。
- 工作視角使用俯視攝影機與固定 HTML 畫布視口；不做桌面上多個視角投影或 VR。
- 日夜／天氣切換 UI、WebRTC、IndexedDB、跨裝置同步仍不在本輪範圍。
