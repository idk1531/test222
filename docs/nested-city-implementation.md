# 嵌套之城：實作尺寸與驗收記錄

## 尺度與構圖假設

概念圖沒有比例尺或可供精確量測的尺寸。以下是供 3D 白模使用的**初始假設**，不是從參考圖量得：建築平面 24 × 20 m、高 16 m；樓板高度為 0、4、8、12 m。相關真相集中在 `src/lib/roomDimensions.ts` 與 `NESTED_CITY`（`src/lib/room3d.ts`）。

- 外層：暖棕木構，包含前／後與兩側的高框架。
- 中層：灰石構件在另一深度方向穿插；水平構件高度與位置不沿用外框。
- 內核：位於偏心位置並旋轉約 13°，不形成同心、等距套盒。
- 由四側環廊、局部平台與橋道保留中央挑空；北側高窗提供自然光與窗外景觀。
- 三段斜坡依序連接地面、4 m、8 m、12 m 樓層；斜坡扶手在落腳區前收止，避免封住轉向口。

## 移動、碰撞與既有功能

玩家姿態帶有目前樓板高度。`groundHeightAt` 依目前高度選取重疊投影下的樓層，斜坡提供連續高度；移動碰撞使用物件的垂直範圍，避免地面家具阻擋上層玩家。相機位置、第三人稱角色、手持書與協作 presence 都會帶入樓層高度，舊版未提供樓層欄位的協作訊息仍預設落在地面。

既有資料書本、分類、桌面預覽、工作畫布、儲存、角色與協作程式仍由原元件管理。樓層上的示意書格只作建築裝飾，不替代資料書本。

HUD 的「白模」切換只把嵌套之城建築改為中性灰白材質與白色結構燈，幾何、家具、資料書本及房間資料不變；關閉後恢復木／石原材質。

## 可重複檢查

```sh
npm run typecheck
npx tsx scripts/check-room3d.ts
npm run test:connection
npm run test:collaboration
npm run test:collaboration-editing
npm run test:shared-content
npm run build
```

`check-room3d.ts` 驗證四層高度、中央挑空、框架偏移／旋轉、三段斜坡連續性，以及斜坡路徑在結構碰撞下可通行；純函式檢查本身不等同瀏覽器視覺驗收。
