## 1. P0 搬牆：書牆移到西牆（左右不再鏡像）

圖一是「左書牆、右窗」。在 three.js 右手系下，面向東北（yaw +45°）時 `right ≈ (+X, +Z)`，北牆必落左側——
單靠機位救不回來。本輪採最小改動：**書架搬到西牆、窗留北牆**，站東南角望向西北（`yaw = −45°`）即得圖一構圖。

- `SHELF.wallSign = FIDELITY.shelfWallSign = -1`（−1＝西牆、+1＝可切回 v8.2 東牆）。
- `SHELF.xBack = (ROOM.width / 2 - 0.16) * wallSign = −2.84`；`SHELF_INWARD = -wallSign = +1` 是所有「牆 → 室內」法向的唯一來源。
- `computeShelfLayout()`：`frontX = shelfFrontX() = xBack + INWARD * (depth − 0.012)`；書本中心 `x = frontX − INWARD * depth/2`。
  兩種牆向下書本都整本落在層板上（v8.2 的東牆公式其實會讓書凸出板緣 1 cm，已順手修正）。
- `Book3D.tsx`：書名標籤 `rotation.y = (−π/2) * wallSign`，`stripe`／`foot` 的 X 偏移同乘 `wallSign`；分類標籤改用 `layout.frontX + INWARD * 0.035`（站在板前緣、面向室內）。
- `WindowLight.tsx`：`SUN.position` 改 `(2.05, 2.45, −3.9)`——仍從窗的左上方進光，但改由**東側**入射，不再從書牆那側穿牆。
- 幾何補正：西牆做成 **0.28 m 厚**（外緣仍在 −3.12），內面正好落在 `SHELF.xBack`，懸浮層板才是真的貼牆
  （v8.2 的背板與牆之間其實藏著 16 cm 空腔，只是看不到）。

## 7. 可退步開關

`src/lib/room3d.ts`：

```ts
export const FIDELITY = {
  shelfWallSign: -1,   // +1 → 書牆回東牆（v8.2 構圖）
  ledge: true,         // 腰高檯面／矮擱板／落地書堆
  blind: "screen",     // "cloth" → v8.2 不透明布簾
  furniture: true,     // 家具
  envMap: true,        // 大理石柔反射（手機本來就跳過）
  decor: true,         // 裝飾書／相框
};
```

`TEXTURES.enabled = false` → 全部回到程序化材質（仍保留 v8.3 的幾何）。房高、窗洞、桌面高度是幾何常數，改 `ROOM`／`WINDOW`／`DESK` 即可逐項回退。

## 10. 已知限制

- 沙箱無瀏覽器（Chromium 缺 libnspr4/libnss3，且無外網可補），**沒有 WebGL 截圖**。
  幾何層級以「真元件 → React effect → 自制 z-buffer 光柵化」離線預覽＋投影斷言交叉驗證，
  材質亮度、簾面透光、大理石反射需在瀏覽器預覽人工確認（可開 `FIDELITY.*` 逐項對比）。
- 窗景仍是「遠景平面＋程序化樹冠／灌木」，非真 3D 庭園（沿用 v8.2）。
- `MATCH_VIEW` 目前只被 `check-room3d.ts` 使用；若要一鍵跳到對照視角，可另開一個 `[data-no-orbit]` 按鈕派發
  `study-room-reset-camera`（會寫入相機狀態，故本輪不預設啟用）。
