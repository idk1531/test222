# v7.2：紙上編輯、節點顏色、工具列配色

發布日期：2026-10-17

本版把「編輯卡片」從另一套表單拉回紙面本身：**預覽與編輯是同一棵元件樹**，只有一層 `CardEditContext` 的 `editable` 旗標不同。同時補上畫布節點顏色與頂部工具列配色兩個外觀自訂功能。

---

## 1. 紙上編輯 ≡ 預覽（R1）

### 架構

- `src/components/CardPaperEditor.tsx`（新檔）
  - `CardEditContext` / `useCardEdit()`：`{ editable, patch, theme }`。
  - 原子元件：`EditableText`、`EditableList`、`EditableSelect`、`EditableToggle`、`EditableCheck`、`EditableRating`、`EditableSlider`、`EditableTagGroup`、`ReadOnlyBadge`、`ApplyBranchTree`。
  - `EditableText` 顯示時走 `MathText`（KaTeX），進入編輯才換成原始碼 `<textarea>`／`<input>`；**不對 KaTeX DOM 做 contentEditable**。
  - 編輯中的格子使用 local draft，`blur` 或 `Ctrl/⌘+Enter` 才 commit，避免每次按鍵都重建整張卡片造成焦點掉落。
- `src/components/CardPaperSections.tsx`
  - 七個分頁 `V6Page1HeaderOverview` … `V6Page7ProcessLogs` 與 `V6ContinuousPaper` 都讀同一個 context；一頁式與分頁式共用同一批頁面元件。
  - P1–P6 的欄位、清單與標記全部改成可編輯；P7 過程日誌維持唯讀，但加上唯讀提示徽章。
- `src/components/CardDetailModal.tsx`
  - 編輯模式新增「紙上編輯 / 進階表單」切換，預設紙上編輯；舊表單完整保留為「進階表單」。
  - 紙上編輯與預覽共用同一個 `paperArea` 與 `pageNav`；編輯時外層包 `CardEditContext.Provider`。
  - 進入編輯時對整張卡片做 `JSON.parse(JSON.stringify(card))` 快照，工具列「還原未儲存」可回復（含頁碼與分頁模式）。

### 互動規則

| 操作 | 行為 |
|---|---|
| 點擊格子 | 進入編輯（顯示琥珀色外框） |
| `Esc` | 取消此格，恢復原值 |
| `Ctrl/⌘+Enter` | 提交並跳到下一個 `[data-editable-cell]` |
| `blur` | 提交 |
| 清單列 hover | 出現 ↑ ↓ ＋ ✕ 控制 |
| 分支列 | 新增同層／子分支、移動、刪除、`[已編譯]` 切換、區域 CHECK |
| 列印 / PDF | 所有控制項 `print:hidden`，只輸出紙面內容 |

### 覆蓋欄位

- **標題與背景**：`title`、`domain`、`shape`、`granularity`、`bloomLevel`、`soloLevel`、`summary`、`v6DemoPreservedNote`、`omittedSlots`。
- **構造思路**：`constructionThinking`、`candidate.*`、`thoughtPoints[]`、`intuitionTraps[]`、`plan.steps[]`、`plan.ranges`。
- **WHY**：`closedBookDraft`、`fullReasoning`（含 KaTeX 原始碼編輯）、`whyProbes[]`、`subGoals[]`、`claims[]`（`epistemicMark`）、`assumptions[]`（`kind` / `status`）、`perspective1/2`、校準信心 1–5。
- **WHAT**：`summary`、`distinctionFromHow`、`readings[]`、`readingQuestions[]`（含 cheapest / invisible / 指向 reading）、`readingBridges[]`、`perspectives[]`（含鏡像視角）、六方向延伸 `extensions.*`、`constructDetails.*`。
- **HOW / APPLY**：`howData.status`、`checks[]`、`can[]`、`branches[]`（`ApplyBranchTree`，支援巢狀與區域 CHECK）。
- **P7 過程日誌**：唯讀（日誌由操作自動產生）。

## 2. 節點顏色（R2）

- 顏色存在畫布物件的 `style.accentColor`（`#rrggbb`），沿用既有 `style` 欄位，**不需**提升 `STORAGE_KEY`。
- 卡片節點右上角新增 Palette 按鈕，開啟 popover：
  - 形狀預設色（A–E、COMPOSITE）；
  - 常用色票；
  - 原生 `<input type="color">` 自訂；
  - 「形狀預設」一鍵移除 `accentColor`。
- 套用位置：頂部色帶、形狀徽章（皆為 inline style，非 Tailwind class）。
- 未設定 `accentColor` 時，使用 `SHAPE_DEFS[shape].hex`，與舊版外觀完全一致。
- `src/lib/store.ts` 的 `updateCard` 在升級舊資料時，若顏色等於舊預設值會自動清掉，避免污染。

## 3. 工具列配色（R3）

- `src/lib/appTheme.ts`（新檔）：`AppTheme` 介面、四組預設（經典白／石墨黑／暖紙米黃／海霧天青）、`DEFAULT_APP_THEME`、`loadAppTheme` / `saveAppTheme`、`useAppTheme()`。
- localStorage key：`scinotes-app-theme`（與工作區資料分離，換工作區不影響）。
- `src/components/AppThemeCustomizer.tsx`（新檔）：預設主題、12 個顏色欄位（`<input type="color">`）、還原預設。
- 套用範圍：header 底色、主要／次要文字、邊線、分頁條、active 分頁、hover 底、強調色、彈窗外框底。
- 所有動態顏色皆以 inline style 套用（Tailwind 無法處理執行期 class）。
- 手機版：側邊選單新增「工具列配色」，面板寬度 `calc(100vw-16px)`、最高 `80vh` 可捲動。
- 編輯／預覽 modal 的外框底色也跟隨 `panelBg`。

## 4. 相容性與資料

- `STORAGE_KEY` 維持 `scinotes-workspace-v7.1`；本版只新增選填 `style.accentColor`，載入舊資料不需要遷移。
- 匯出／匯入 JSON 會原樣帶上 `accentColor`。
- 種子卡片的審查分數不受影響：`scripts/audit.ts` 六張卡皆為 `Score: 100 | Total Issues: 0 | Critical: 0`。
